# Security

Report suspected vulnerabilities privately to [contact@appik-studio.ch](mailto:contact@appik-studio.ch?subject=Askolia%20Convex%20security). Include the affected version, reproduction steps and expected impact. Do not include live credentials or private document content.

Do not open a public issue with an unpatched vulnerability. Rotate any exposed integration token through the project owner.

Integration tokens belong in the consuming Convex deployment's server environment. Documents synchronized by this component become part of the selected Askolia project's public knowledge. Authorize your host functions before exposing them to clients.
